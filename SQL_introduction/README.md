# SQL - Introduction

This project introduces relational databases, SQL, and MySQL: how to
create and delete databases, create and describe tables, and perform
basic DDL/DML operations (INSERT, SELECT, UPDATE, DELETE) along with
aggregate functions like COUNT, AVG, and GROUP BY.

## Learning Objectives
- What's a database, and what's a relational database
- What SQL stands for, and what MySQL is
- How to create a database in MySQL
- What DDL and DML stand for
- How to CREATE or ALTER a table
- How to SELECT, INSERT, UPDATE, or DELETE data
- What are subqueries, and how to use MySQL functions

## Requirements
- Ubuntu 20.04 LTS, MySQL 8.0 (8.0.25)
- All files end with a new line
- Every file starts with a comment describing the task
- Every SQL query has a comment directly above it
- All SQL keywords are uppercase (SELECT, WHERE, etc.)
