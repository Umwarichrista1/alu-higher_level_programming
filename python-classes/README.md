# Python - Classes and Objects

This project introduces Object-Oriented Programming in Python:
classes, objects/instances, attributes, methods, `self`, the
`__init__` method, data abstraction/encapsulation, private/protected
attributes, and the Pythonic use of properties as getters and
setters.

## Learning Objectives
- What is OOP and "first-class everything"
- What is a class, an object, and an instance
- What is an attribute, and public/protected/private attributes
- What is `self` and what is a method
- The special `__init__` method
- Data Abstraction, Data Encapsulation, and Information Hiding
- What is a property, and how it differs from a plain attribute
- The Pythonic way to write getters and setters
- How to dynamically add attributes to an instance
- What `__dict__` contains and how attribute lookup works
- How to use `getattr`

## Requirements
- Ubuntu 20.04 LTS, python3 (3.8.5)
- All files start with `#!/usr/bin/python3`
- All files end with a new line
- All files are executable
- Code follows pycodestyle 2.7.*
- Every module, class, and method has a real docstring
