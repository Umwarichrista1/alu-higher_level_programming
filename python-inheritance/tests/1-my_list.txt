The ``1-my_list`` module
=========================

Using ``MyList``
-----------------

    >>> MyList = __import__('1-my_list').MyList
    >>> my_list = MyList()
    >>> my_list.append(1)
    >>> my_list.append(4)
    >>> my_list.append(2)
    >>> my_list.append(3)
    >>> my_list.append(5)
    >>> my_list
    [1, 4, 2, 3, 5]

Printing sorted does not change the original order:

    >>> my_list.print_sorted()
    [1, 2, 3, 4, 5]
    >>> my_list
    [1, 4, 2, 3, 5]

An empty MyList prints sorted as an empty list:

    >>> empty = MyList()
    >>> empty.print_sorted()
    []

Sorting handles negative numbers too:

    >>> neg_list = MyList()
    >>> neg_list.append(3)
    >>> neg_list.append(-5)
    >>> neg_list.append(1)
    >>> neg_list.print_sorted()
    [-5, 1, 3]
