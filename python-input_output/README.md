# Python - Input/Output

This project covers reading and writing files in Python, along with
JSON serialization and deserialization: converting Python data
structures to JSON strings and files, and back again.

## Learning Objectives
- How to open, read, and write a file
- How to read a file line by line and move the cursor in a file
- How to make sure a file is closed after use, and what the `with`
  statement does
- What is JSON, serialization, and deserialization
- How to convert a Python data structure to a JSON string and back

## Requirements
- Ubuntu 20.04 LTS, python3 (3.8.5)
- All files start with `#!/usr/bin/python3`
- All files end with a new line
- All files are executable
- Code follows pycodestyle 2.7.*
- Every module, class, and function has a real docstring

## Files
| File | Description |
|------|-------------|
| 0-read_file.py | Print the content of a text file |
| 1-write_file.py | Write text to a file, creating/overwriting it |
| 2-append_write.py | Append text to the end of a file |
| 3-to_json_string.py | Convert an object to a JSON string |
| 4-from_json_string.py | Convert a JSON string to an object |
| 5-save_to_json_file.py | Save an object as JSON to a file |
| 6-load_from_json_file.py | Load an object from a JSON file |
| 7-add_item.py | Add CLI arguments to add_item.json |
| 8-class_to_json.py | Serializable dict description of an object |
| 9-student.py | Student class with a to_json() method |
| 10-student.py | Student class with a filterable to_json() |
| 11-student.py | Student class with reload_from_json() |
| 12-pascal_triangle.py | Build Pascal's triangle of n rows |
